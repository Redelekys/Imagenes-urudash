# Repo destinado a almacenar las fotos de perfíl de los usuarios de la [Uruguay Demonlist](https://docs.google.com/spreadsheets/d/1sLqNc3NxZUY1K00KOGJhRIq1FKkDEwH4npjuAVDCQvI/edit?ouid=105887668245654839394&usp=sheets_home&ths=true)

Modo de uso
1) Subir la imagen al repo asegurando que el nombre se acorde con el nombre del jugador (ej: neuron.png)
2) Ir a la hoja "players" en la UYDL y buscar la template
3) editar la formula de la template con el nombre del archivo correspondiente al jugador. (ej: =IMAGE("https://raw.githubusercontent.com/Redelekys/Imagenes-urudash/main/neuron.png",1
4) copiarlo en la columna AVATAR URL en la fila del jugador correspondiente.
